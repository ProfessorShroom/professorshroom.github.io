VentPuck

A round touch-screen OBD2 gauge that sits in the air vent of my Megane RS

I drive a Renault Megane RS and I wanted to see things like boost and oil temperature while I’m driving, without bolting a gauge pod to the dash or having a phone propped up on the vent.

So I’m building VentPuck, a small round gauge that sits in one of the air vents and reads live data from the car.

It’s built around an ESP32-S3 with a 1.85” round touch display. The car’s data comes over any Bluetooth OBD2 adapter that supportrs BLE, so the only wires to the gauge itself are for power. The screen shows one big reading in the middle, with oil and coolant temperature always visible at the bottom, and you swipe to change the main reading. At the moment that’s coolant temp, oil temp, boost, RPM, speed and battery voltage, and I’m planning a few more like intake air temp and a G-meter (the board has an accelerometer built in).

The interface is written with LVGL. Everything that’s specific to a car (the custom PIDs, the gauge ranges and the warning colours) lives in a small profile file, so it should be easy to adapt to other cars. The first profile is for the Megane RS (250/265/275).

It’s still a work in progress. The standard readings like coolant, boost, RPM and voltage work on any OBD2 car, but oil temperature isn’t a standard PID on Renaults, so I’m still working out the right request for my ECU.

All the code is on the repo page.

Changelog

## VentPuck **_Copyright © Charlie Howard 2026 All rights reserved_** A small round touch-screen gauge for your car's air vent. It reads live data from the OBD2 port over Bluetooth LE and shows it on a 1.85" round display, running on an ESP32-S3. Built for my Renault Megane RS (Mk3), but the car-specific parts are kept in a profile file so it can be adapted to other cars. This is an early work in progress, so there's nothing to download yet. ### Features - One big main reading, swipe left/right to change it - Oil and coolant temperature always shown at the bottom - Main readings: coolant temp, oil temp, boost, RPM, speed and battery voltage - Planned extras: intake air temp, engine load, peak boost hold, G-meter (the board has a built-in accelerometer) and reading/clearing fault codes - Car-specific PIDs, gauge ranges and warning colours live in a profile file ### Hardware - **Display / controller** - an ESP32-S3 board with a 1.85" 360x360 round capacitive touch display - **OBD2 adapter** - any Bluetooth OBD2 adapter that supports **BLE** ELM327-style adapter. The ESP32-S3 doesn't support Bluetooth Classic, so Classic-only adapters won't work. I used the OBDLink CX as it supports a sleep function to reduce power drain when the car is parked for longer than a few days, but the cheaper ones will work fine. - **Power** - 12 V to 5 V buck converter on a switched fuse tap, so the gauge turns on and off with the ignition ### Status The standard readings (coolant, boost, RPM, speed, voltage) work on any OBD2 car, with boost worked out from MAP minus barometric pressure. Oil temperature isn't a standard PID on Renaults, so I'm still working out the right request for the Megane RS ECU. ### Changelog #### Latest Update **Version 1.0.0** - **_1.0.0_** Initial commit: project name, logo and README.
