Enabling RS Drive 2 in a Megane MK3

Created on October 30, 2026

2026   ·   renault   megane   rs monitor   rs drive   retrofit   renaultsport   car   guide   ·   Car

I don’t know why, but some cars that have RS Monitor don’t have RS Drive 2 enabled, which basically allows you to change throttle response, traction control, and the engine map per mode, Normal, Sport and Race. This is a guide on how to enable that via DDT4ALL.

There aren’t any English guides on this so I thought I’d make one, it’s actually very easy to do.

First you’ll need a modified ELM327 adapter like this one designed for Ford as they use the same pinout as Renault. For this to work you’ll need the driver which you can download here, just plug in the ELM and install the driver. Then you’ll need DDT4ALL, download the latest release for your system. At the time of writing this I was using 3.1.3. DDT4ALL doesn’t ship with database files, here’s database files from February 2021, just unzip and place all of the folders/files into the DDT4ALL install folder.

Once you have DDT4ALL setup we need to go over to the car and plug in the ELM adapter to the OBD port and the laptop. Make sure the ignition is on (just put the key in the slot) and then run DDT4ALL. Make sure you accept the disclaimer and then select Connected mode.

You’ll also need to make sure that the adapter is in the correct mode to communicate with the infotainment system rather than engine computer. On the adapter I linked above when it’s plugged in and the sticker is facing up, the metal switch should be in the down position. If for whatever reason the next steps don’t show the correct results just flip it and try again.

As below, select “[X95PH2] - Renault Megane III Ph2” from the dropdown, it will work without doing this however the next step will take a lot longer as it will search for every single ECU, not just the Megane III ones.

Then press scan button to the right of the drop down menu, it looks like a QR code with a magnifying glass next to it and wait, it should take a couple of minutes to scan.

Once the scan has finished you should see some ECUs appear in the Ecu window below, the one we’re looking for should be named “MFD v5.4” or something very similar.

Once you click on “MFD v5.4” you’ll see some new options appear below in Screen window, expand “1 - Configuration”, then select “14 - ECU configuration - HMI.TMPS,RestrictionVIN,RS Display & Communication”. As seen below.

As you can see above the main window should contain a bunch of red, green and yellow boxes. Scroll down until we get to “RS DISPLAY” with 3 options below it. The one we are interested in is “RS Configuration Slot 1”. Slot 2 isn’t needed for what we’re doing.

Before we go any further I highly suggest you copy and save Slot 1 and 2 (even though we’re not touching 2, it’s good practice) somewhere safe just in case the edit goes wrong so you have your original figures. You copy from the red boxes on the left, it won’t let you copy from the right side.

On another note, if anyone follows this guide on a Megane 265, can you please comment your Slot 1 and 2 figures below as I’ve not come across those yet, and I’ll add them here.

I’ll be using a Megane 275 slot as an example. Below is the original Megane 275 slot 1 with two modified ones (the first one just enables RS Drive, the second one enables RS Drive but also makes other readouts a lot more useful like coolant temp and oil temp, as it lowers the values needed to display them. For example normally oil doesn’t display until 50C, but with this it displays from 0C). I’ll also add slot 2 just in case anyone needs or wants it, but we don’t need it for this.

If you look, only the last part of the slot is changed, this tells the car to enable RS Drive.

Make sure that these two buttons are pressed at the top of DDT4ALL, “Expert mode” and “Auto refresh”. Expert mode allows writing to the ECU, and auto refresh just reads the ECU automatically which makes it easier to know if your write worked.

Now just copy and paste one of the modified slot 1 codes from above and paste it over the contents in “RS Configuration Slot 1” (or clear the box first) and then press “Write RS Slot1”, it will be hard to tell but the contents of the green box should also change.

At this point it should be done, I had to disconnect the battery on my car for it to appear. You may be able to just leave the car for a few hours, or try pressing the home button 5 times quickly which reboots the screen, but I didn’t try this.

Now you can access RS Drive from within RS Monitor and change settings from there.

For anyone that’s interested in what slot 2 does, it basically manages the torque and power graphs in RS Monitor, changing these does not change the map on the car, its for display only. On a standard car you don’t need to change these but on a mapped/modified one you can change this to reflect the real power of the car as I have done on my Megane RS400.

For anyone wanting to do this, here is a spreadsheet which allows you to input new figures and generates a new code for you. If you do this you also need to edit slot 1 again with the new peak power and torque figures.
